# NEXXI Kids storefront

The WordPress theme in `wp-content/themes/nexxi-kids/` renders the nine original Stitch screens with local copies of their image assets. The companion plugin in `wp-content/plugins/nexxi-kids-commerce/` adds the reference size guide and WooCommerce size/color cart data.

Install from `nexxi-kids-theme.zip` and `nexxi-kids-commerce-plugin.zip`; see [WORDPRESS-SETUP.md](WORDPRESS-SETUP.md). Run the local WordPress preview using [DOCKER-PREVIEW.md](DOCKER-PREVIEW.md). The root HTML files are static design references, while `stitch-export/` contains the original Stitch HTML, screenshots and logo.

Screens: home, shop, product detail, flash sale, cart, checkout, login, account and membership.
